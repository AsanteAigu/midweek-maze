# 🖼️ INSPIRATIONS FOLDER — ISAG Quiz Platform

This folder contains UI inspiration images for Claude Code to reference when building the frontend.

## Design Direction
Dark, competitive, technical — like a leaderboard in an engineering lab. Think gaming leaderboards meets academic platform. Electric teal on near-black. Pixel avatars. Monospace data.

## Design References To Screenshot & Add Here

Save screenshots as .png files in this folder before running Claude Code.

## Notes For Claude Code
> Reference these images for the dark, competitive aesthetic.
> ISAG Quiz Platform is NOT a light theme app — dark backgrounds only.
> Electric teal (#00E5CC) is the accent — not green, not blue, not purple.
> Pixel avatars (DiceBear) are the identity system — feature them prominently.
> Leaderboard is the hero element — it should feel like a live scoreboard.
> Monospace fonts for all data values (XP, rank numbers, student IDs).
